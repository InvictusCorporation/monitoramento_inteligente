# Importação e integração

## Situação

O código da aplicação ainda não está presente. A documentação e o `.gitignore` preparam o repositório para receber os arquivos de programa.

## Importar a fonte

1. Usar uma cópia dos arquivos de programa da versão existente.
2. Conferir a versão e ler as instruções do projeto antes de alterar o código.
3. Excluir dados de clientes, imagens de câmeras, bancos de dados, arquivos privados de configuração, chaves e backups.
4. Conferir o conteúdo do commit antes de enviar ao repositório.

## Integrar e validar

1. Adaptar a interface aos contratos reais de autenticação, câmeras, vídeo, análise, ocorrências e licenças.
2. Preservar a autorização e o isolamento entre clientes e empresas no servidor.
3. Validar o acesso aos equipamentos na arquitetura de implantação escolhida.
4. Testar login, vídeo, fotos, análise, atendimento, finalização, pausa e reativação dos alertas.
5. Testar quotas, backup, restauração e comportamento após falhas de conexão.
6. Executar os testes do conjunto integrado e documentar os resultados.

A validação de uma interface demonstrativa e a validação de um serviço isolado não substituem a validação do sistema integrado. A publicação operacional depende da conclusão dessas etapas.
